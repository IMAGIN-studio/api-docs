# IV. Service APIs

Our Service APIs are configuration utilities that clients can use to build custom dashboards, internal tools, and interactive showroom widgets

| **Page Title**                                                                                                                                                             | **Description**                                                                                                                                                                                    |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

It is designed to act as the pipeline for your internal dashboards, back-office tooling, and user-facing inventory widgets. |
| <h2><a href="https://docs.imagin.studio/guides/getting-images/iii.-deployment-and-integration-guides-1/setting-up-color-swatches"><code>getPaints</code></a></h2>          | This endpoint returns the valid paint codes available for a given make/vehicle in the IMAGIN.studio catalog.                                                                                       |
| <h2><a href="https://docs.imagin.studio/guides/getting-images/iii.-deployment-and-integration-guides-1/setting-up-color-swatches-1"><code>getPaintSwatches</code></a></h2> | An API to retrieve the necessary color information to generateg paint tiles or color swatches within your application.                                                                             |
